# TeX 题面、样例与题解

编写、修改、翻译题面或题解时读取本文件。按照项目现有 TeX 模板和平台字段组织源文件。

## 题面语义

从已确定的数学定义组织背景、问题、输入、输出、约束与样例说明。核对量词、相等与严格不等、下标、闭区间、操作顺序、可重复性、空对象、无解表示和容差。

单测试约束和跨测试总量分别写清，逐项与 validator 对照。翻译时对照语义和全部约束，避免只做文字润色。若现有定义未确定，先记录歧义及能区分解释的实例。

## 样例来源

使用同一组样例输入输出作为数据与题面引用来源；按照项目模板决定嵌入方式。

1. 用 validator 检查样例输入。
2. 用已核对的解重新计算答案；多解题验证题面展示的具体答案即可。
3. 复核样例解释中的每一步操作和数值。
4. 若修改样例，重算输出并同步所有语言版本。

用手算或独立小规模逻辑补充样例验证。样例通过的结论限定于样例。

## 渲染与题解

Polygon 的 TeX 使用平台支持的命令与模板。HTML 和 PDF 分别渲染与查看，重点检查公式、表格、上下标、转义、换行、图像和样例。需要平台渲染时读取 [polygon.md](polygon.md)。

本地 TeX 编译结果、平台 HTML 结果与平台 PDF 结果分开记录。缺少渲染工具或远端环境时保留源文件并标记对应格式未验证。[Polygon TeX 手册](https://polygon.codeforces.com/docs/statements-tex-manual)

题解维护 TeX 源文件，写清关键观察、完整算法、证明、复杂度和实现要点。核对状态定义、边界、数值范围与最终代码一致；说明错误思路时使用已确认的反例。

完成条件：请求范围内的 TeX 与附件已更新，语义对照和样例复算有记录，实际完成的渲染格式及剩余缺口明确。
