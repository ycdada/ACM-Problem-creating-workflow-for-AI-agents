# 题目还原与数据制作报告

使用项目已有格式，或在题目目录写入 `reports/reconstruction.md`。结论绑定本次材料和程序版本。

## 来源与规格

- 原题标题、题号、链接或用户提供文件、获取日期和版本标识。
- 本次目标、输出目录、材料是否完整、题型和平台适配范围。
- 关键规则与约束的来源位置；原文事实、推导、假设和待确认项分开列出。
- 原始样例、疑似笔误或冲突及其处理状态。

## 解法与答案来源

- 算法、证明、复杂度、数值类型与适用范围。
- 标程、暴力或独立判定的路径、版本及独立程度。
- 样例复核、穷举、对拍的实际范围，命令、环境、结果和反例位置。
- 若执行过原平台提交，记录实际语言与判定；未提交则如实说明。

## 数据清单

每个数据组记录其性质与测试目的、规模、生成器和完整参数、随机约定、依赖版本、文件或清单位置、输入与答案哈希以及答案来源。

区分原题提供的样例或测试、自行构造的数据、随机生成的数据和发现的回归反例。自行生成的集合不标为原题隐藏数据。

列出 validator 正反例、自定义 checker 测试、错误解结果矩阵和适用的性能测试。预期错误解未被检出时说明缺口，运行错误与目标缺陷区分记录。

## 交付状态

按规格、样例、输入校验、判题、答案、覆盖、TeX、平台等适用项分别给出“已验证 / 失败 / 未执行 / 待确认”。

记录用户确认的补充约束、格式变化与平台差异。明确哪些内容可供正式交付，哪些仅是条件性探索或尚缺证据；给出复现方式和剩余事项。
